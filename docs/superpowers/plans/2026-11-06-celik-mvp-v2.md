> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the built milestone-2 app into the hybrid Celik MVP (financial literacy core loop, scams as high-stakes events), filmable by 9 Nov 2026.

**Architecture:** Unchanged from v1: pure TypeScript `engine/` built test-first (now including `finance.ts`), zustand `state/` saved through `storage/`, `shell/` plus one folder per mode under `modes/`, content in repo-root `content/` compiled and validated by the Vite plugin.

**Tech Stack:** Vite 8, React 19, TypeScript 6, Tailwind 4, framer-motion, inkjs 2.4, zustand 5, zod 4, Dexie 4, vite-plugin-pwa 2, Vitest 5, @playwright/test 1.65. No chart library (SVG by hand).

**Spec:** `docs/superpowers/specs/2026-11-06-celik-mvp-design.md` plus the v2 docs: `docs/DECISIONS.md` (D18-D33 win over everything), `docs/SRS.md` v2, `docs/SDS.md` v2 (5.1-5.8), `docs/UI-SPEC.md` v2 (S03, S11, S12, S19-S21), `CLAUDE.md`, `docs/superpowers/pivot-review.md`.

**Supersedes:** tasks 11-25 of `docs/superpowers/plans/2026-11-06-celik-mvp.md`. Tasks 1-10 of that plan are done (commits up to c33b359).

## Global Constraints

- Everything in v1's Global Constraints still holds (fictional brands, `.test` links, `01X-0000 0NNN` numbers, no real-data inputs, SimulasiBanner, offline, ≤ 8 MB, BM default with i18n keys, `legal.*` keys in `_todoVerify`, tunables in `balance.ts`, no shaming, 16 px text / 48 px targets / reduced motion, DEMO watermark, three viewports, hash routing with `base: './'`, commit trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`, `frontend-design` skill before UI work).

- No investment advice: explain and show how to check, never recommend; every rate is labelled "contoh" and its source/year is `TODO-VERIFY` (CLAUDE.md rules 11-12).
- All money maths lives in `app/src/engine/finance.ts` with unit tests; results round to the nearest sen (NFR-16).
- Direction (D18): when a trade-off comes up, protect the SRS 5.2 video path.
- Routes register in `app/src/shell/routes.tsx` `ROUTE_TABLE` (also the bare tile path) and in `app/e2e/routes.ts` `ROUTES`.
- Component tests start with `// @vitest-environment jsdom`.
