# Celik MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Celik, an offline-first phone-simulator PWA where first-year Malaysian students play through a semester of money decisions and scams, play the scammer, and learn real protective actions, polished enough to film by 9 Nov 2026.

**Architecture:** A pure TypeScript `engine/` (rules, tag parser, ink story runner, scheduler, grade, persona model) built test-first; zustand stores in `state/` saved to IndexedDB through `storage/`; a fake-phone `shell/` and one folder per mode under `modes/`. Content (`.ink` scenarios and JSON) lives in the repo-root `content/`, compiled and validated by a Vite plugin at build time.

**Tech Stack:** Vite 8, React 19, TypeScript 6, Tailwind CSS 4 (`@tailwindcss/vite`), framer-motion 14, inkjs 2.4, zustand 5, zod 4, Dexie 4, vite-plugin-pwa 2, html-to-image, lucide-react, @fontsource (Plus Jakarta Sans, Inter, JetBrains Mono), Vitest 5 (+ jsdom, @testing-library/react, fake-indexeddb), @playwright/test 1.65 (Chromium).

**Spec:** `docs/superpowers/specs/2026-11-06-celik-mvp-design.md`. Also read `CLAUDE.md`, `docs/DECISIONS.md` (wins over everything), `docs/SRS.md`, `docs/SDS.md`, `docs/UI-SPEC.md`, `docs/claude-code-prompt.md`.

## Global Constraints

- Fictional brands only. Real items allowed: `997` and `https://semakmule.rmp.gov.my`, opened only from a button labelled "Buka Semak Mule sebenar".
- In-game links: `<name>.test/<path>`, never `http://`. In-game phone numbers: `01X-0000 0NNN` (e.g. `011-0000 0123`).
- No inputs for real names, IC, bank accounts, OTP or passwords. The only free-text input is the character's display name (pre-filled "Aina"/"Amir"). Simulated bank/portal/997 screens show `SimulasiBanner`: "SIMULASI - bukan laman/aplikasi sebenar".
- No run-time network calls after first load. No CDN, analytics or AI. First download ≤ 8 MB.
- BM is default; every visible string is an i18n key in `app/src/shell/i18n/ms.json` (EN in `en.json`, falls back to MS). Scenario text is BM inside `.ink`.
- Legal sentences (Penal Code 424A-424D, NSRC procedure, bank rules) are keys under `legal.*` listed in `ms.json` → `"_todoVerify": [...]`.
- Every tunable number lives in `app/src/engine/balance.ts`.
- No shaming copy; never the word "bodoh". Consequence screens always offer **Cuba lagi**.
- Text ≥ 16 px on phone (≥ 32 px in Mod Kelas), touch targets ≥ 48 px, colour never the only signal, `prefers-reduced-motion` → fades under 200 ms.
- DEMO watermark: top right, 40% opacity, on by default, toggle in Settings.
- Viewports to check: 360x800, 412x915, 1920x1080.
- Hash routing and Vite `base: './'` so the build runs on GitHub Pages or Netlify unchanged.
- Folder ownership stays separate: `app/src/{engine,state,storage,shell,modes,ui}`, `content/`, `assets/`.
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- UI tasks: the implementer invokes the `frontend-design` skill before building screens and follows UI-SPEC tokens (section 1) exactly. It must feel like a warm Malaysian phone, not a dashboard.

## Review Focus

1. **Reload or close mid-scenario** → the scenario restarts from its beginning with meters restored to the pre-scenario snapshot; effects are never applied twice. Test in Task 7.
2. **Money runs out** (big scam, hostel fee) → Duit floors at RM0, Simpanan never exceeds Duit, BankKu shows RM0.00 without negative numbers. Test in Task 6.
3. **Double-tap** on a reply chip, **Sahkan** or a swipe button → the action happens once. Tests in Tasks 9, 12, 14.
4. **Daily streak across dates** → same day: unchanged; next day: +1; gap of 2+ days: reset to 1; device clock moved back: unchanged. Test in Task 14.
5. **Long BM strings on a 360 px screen** → no horizontal scrolling on any screen. Assertion in the screenshot runner (Task 8).

## Shared interfaces (defined in Tasks 2-6, used everywhere)

```ts
// engine/types.ts
export const TACTICS = ['greed','urgency','authority','fear','secrecy','social','payfirst'] as const;
export type Tactic = typeof TACTICS[number];
export const FAMILIES = ['job','mule','investment','parcel','authority','loan','payment','bank','marketplace'] as const;
export type Family = typeof FAMILIES[number];
export type Outcome = 'scammed' | 'mule' | 'frozen' | 'safe' | 'curiga';
export type Akaun = 'Aktif' | 'Disekat' | 'Ditutup';
export type Rekod = 'Bersih' | 'Disiasat' | 'Didakwa';
export type Effect =
  | { kind: 'duit'; delta: number } | { kind: 'tekanan'; delta: number }
  | { kind: 'akaun'; value: Akaun } | { kind: 'rekod'; value: Rekod };
export interface Flag { tactic: Tactic; phrase: string }
export type UiDirective = { kind: 'transfer'; amount: number } | { kind: 'link'; url: string };
export interface ScenarioMeta {
  id: string; type: 'scam' | 'legit'; family: Family; tactics: Tactic[];
  contact: string; number?: string; ui: 'chat' | 'call'; hint?: string; apaPatut: string[];
}
export interface Meters {
  duit: number; simpanan: number; tekanan: number; xp: number;
  imuniti: Record<Tactic, number>; akaun: Akaun; rekod: Rekod;
}
export interface ScenarioResult { id: string; outcome: Outcome; right: boolean; flagsFound: number; flagsTotal: number; tactics: Tactic[]; family: Family }
export interface CompiledScenario { meta: ScenarioMeta; json: string; flags: Flag[] }
```
